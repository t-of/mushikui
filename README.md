# mushikui — 虫食い算

筆算の空いているマスを埋める虫食い算。かけ算・わり算が中心。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/mushikui/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

- 「かけ算」「わり算」（おまけで「たし算」「ひき算」）を選ぶ。一覧は虫食い（□）の数で区分（上のタブから飛べる）。
- 一覧で問題を選ぶ。筆算の空いているマスをタップし、下の数字パッドで数字を入れる（キーボードの数字・矢印・Backspace でも操作できる）。
  マスの大きさは画面の幅と高さに収まる最大になる（問題・画面サイズが変わるたびに測り直す）。
- 全部埋めたら「答え合わせ」。合っていれば「せいかい！」、違うマスは赤くなる。「答えを見る」で答えを表示できる。
- 「次の問題 →」で次の問題（区分の中を簡単な順＝空きマスが少ない順に進み、区分をまたいで進む）に進む。解いた問題は一覧で色が付く。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

問題データ（`data/<op>/`）は、全探索済みの `puzzles_*.jsonl`（見えている数字が 1 つだけで解が唯一のもの）
から作ってある。九九レベル（かけ算で片方が 1 桁、わり算で割る数が 1 桁）は簡単すぎるので除く。
虫食い（□）の数ごとに `manifest.json`（id の並びと件数だけ。軽い。一覧が読む）と
`blanks-<n>.json`（その区分の問題本体。開くときだけ読む）に分けてあり、わり算のように件数が多くても
1 ファイルが大きくなりすぎない。id は演算と問題の図から作る短いハッシュで、並び順が変わっても
`mushikui.solved`（解いた印）の対応が壊れない。

jsonl は探索が進むたびに追記されるので、増えたら同じコマンドで作り直せる（読み直すだけ）。

```sh
node tools/make-data.mjs [探索データのフォルダ]   # 既定: ~/GitHub/tof/drafts/mushikui/search
```
